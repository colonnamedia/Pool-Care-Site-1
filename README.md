# Clearline Pool Care — FireWorks Template

Reusable static pool-maintenance website template for the FireWorks storefront. Clearline Pool Care is fictional. All business details are sample content.

## Local verification

```bash
npm test
npx serve .
```

The demo form validates locally and intentionally does not send, store, upload, schedule, enroll, confirm, or charge.

## Live paths

- `/` home
- `/services` routine care and equipment observations
- `/residential` homeowner path
- `/commercial` facility path
- `/seasonal` openings and closings
- `/plans` recurring plans and provider gates
- `/service-areas` coverage placeholders
- `/quote` detailed local-only intake
- `/preview` FireWorks overview
